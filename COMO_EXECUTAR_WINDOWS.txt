SGDI v5 PARA WINDOWS — versão de 27/10/2026

1. Instale Python 3.11 ou superior: https://www.python.org/downloads/windows/
   Habilite o launcher py ou Add python.exe to PATH.
2. No GitHub, use Code > Download ZIP e EXTRAIA a pasta inteira.
   Não execute de dentro do ZIP. Escolha uma pasta gravável pelo seu usuário.
3. Abra INICIAR_WINDOWS.bat com dois cliques.
   A primeira instalação precisa de internet para baixar dependências.
4. Escolha: 1 demonstração; 2 sistema sem login; 3 autenticado; 4 testes; 0 sair.
5. Abra o endereço informado no navegador. Para parar, use Ctrl+C.
   Se perguntado se deseja finalizar o arquivo em lotes, confirme.

COMPATIBILIDADE
- tzdata fornece America/Sao_Paulo no Windows.
- Gunicorn é instalado somente fora do Windows.
- Conexões SQLite temporárias são fechadas explicitamente após commit/rollback.
- Arquivos BAT usam caminhos entre aspas e finais de linha CRLF.
- GitHub Actions executa testes em Windows e Linux: veja a aba Actions.

O menu configura execução local para aula; não instala hospedagem pública.
